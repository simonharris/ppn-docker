Yes, this is the very site you're looking at now.

It started off as a sort of end-of-term project for the London App Brewery's "100 Days of Python" course, which you can find on Udemy. That's actually a really well-designed course, and Angela is a personable and engaging host.

To justify including it here as a project in its own right: because it's such a simple project, I used it as an opportunity to stretch my legs with a bunch of technologies that I wasn't hugely experienced with.

The front end is a Vue.js single page application, backed up by an API built on the Flask framework for Python, sand there's a simple Sqlite database.

The whole lot is containerised in Docker, which has greatly simplified deployment: the API, site and database always travel together, so Docker effectively reduces them down to one coherent project.

You're already on the site, so the "Visit Project" button is a link to the project's source code on GitHub.
